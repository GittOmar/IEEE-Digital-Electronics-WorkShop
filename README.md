# Session 1: Introduction to Digital Electronics  

## 📌 Overview  
This session introduces the fundamentals of digital electronics, including the differences between digital and analog systems, digital design flow, logic gates, and Verilog basics.  

## 📝 Topics Covered  
1️⃣ Introduction to Digital Electronics  
2️⃣ Digital vs. Analog Systems  
3️⃣ Digital Design Flow  
4️⃣ Logic Gates and Technology Mapping  
5️⃣ Break ☕  
6️⃣ Verilog Basics  
7️⃣ Hands-on Coding with Verilog  
8️⃣ Lab 1: Getting Started with Verilog  
9️⃣ Lab 2: Practical Verilog Implementation  

## 💻 Lab Exercises  
📂 **Lab 1: Getting Started with Verilog**  
- Writing basic Verilog code  
- Understanding modules, inputs, and outputs  

📂 **Lab 2: Practical Verilog Implementation**  
- Implementing basic gates using Verilog  
- Running simulations  

## 🔧 Prerequisites  
✔ Basic understanding of circuits  
✔ Familiarity with binary numbers  
✔ Installed Verilog simulator (e.g., ModelSim, Xilinx Vivado, or Quartus)
